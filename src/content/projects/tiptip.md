## The Problem

Tiptip is a multi-product platform covering knowledge sharing, event ticketing, and research. Each product had different testing needs, and the team needed a unified test automation strategy that could scale across all three.

## What I Built

As Lead Software Engineer in Test, I built and managed the test automation infrastructure across all Tiptip products.

**Scope:**
- **Knowledge platform**: Content management, user interactions, subscription flows
- **Event ticketing**: Ticket sales, registration, payment processing
- **Research tools**: Data collection, survey logic, analytics

**Key contributions:**
- Built test automation framework from scratch
- Achieved 90% automation coverage across all products
- Reduced regression testing effort by 85%
- Improved API performance by 30% through load testing and optimization
- Set up CI/CD pipelines with automated test runs

- **Playwright + Selenium**: Browser automation across different product needs

- **CI/CD integration**: Every PR triggers automated test suite
- **API testing**: Load testing and performance validation
