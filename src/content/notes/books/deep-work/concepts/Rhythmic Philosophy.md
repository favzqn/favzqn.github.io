# Rhythmic Philosophy

Build a regular daily habit of deep work. Same time every day.

---

## How It Works

- Set a specific time each day for deep work
- Build a chain/habit (don't break the chain)
- Make it automatic, not a decision

---

## Example

- Write every morning from 7-9am
- Deep code every afternoon from 2-5pm
- The key is consistency, not intensity

---

## When to Use

- Most people, most situations
- When you have a regular job with shallow obligations
- When you need to build the deep work habit gradually
