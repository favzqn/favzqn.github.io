## The Core Idea

The Silva Method teaches that creative problem-solving works best in the alpha brainwave state — the relaxed, receptive state between waking and sleeping. Beta analyzes; alpha creates. The key is to define the problem clearly, enter alpha, and let the solution emerge.

See [[Creative Problem Solving]] for the full treatment, including:
- The beta/alpha distinction
- The letting-go principle
- Using the Mental Screen to project problems
- Dream Control for overnight solutions
